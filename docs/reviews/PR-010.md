## Native evidence and integration decisions

- **Cards.** `AzerothSurvivors/Cards.lua:971–1014` shows the native Shift and late offered-tooltip flows. `FillCards` places three or four cards, applies the native description and rarity, and presents multiple bonus lines. `Cards.lua:1307–1491` retains the original native interaction and decision handling. SurvivorUI reuses the existing `Fit` hook, reads bonus text already formatted by the game, and uses only the published structured before/after values for that same offer when parsing succeeds. The label preserves each native gain and unit. A long card that exceeds the classic layout returns to its native presentation. `Options.lua` uses the existing Modules and paired game tick for immediate switching, with the chosen mode stored in the existing settings database. The native mode restores the game geometry, art, comparison text and font. No game actions or new network requests are issued by the adaptation.
- **Nameplates.** `AzerothSurvivorsAPI/Anchors.lua:248–285,595–601` classifies world ranks and uses the low GUID for bosses and guardians. `Api.lua:686–713` implements native unit classification. The bundled `AzerothSurvivorsUI` registers `NAME_PLATE_UNIT_ADDED` and `NAME_PLATE_UNIT_REMOVED` and uses `C_NamePlate.GetNamePlateForUnit` in `Libs/oUF/ouf.lua:793–879`. SurvivorPlates consumes the same event mapping when present, at receipt. It reuses the current anchor cadence and per-kind preferences and adds no per-frame unit scan. An affected unit with no reliable native frame token, ranked anchor or known legacy fallback cannot be assigned a precise kind. No new name catalog was shipped.
- **Run UI.** `AzerothSurvivors/Run.lua:173–197` gives the two objective labels and their state color. `Tracker.lua:531–551` and `AzerothSurvivorsAPI/Hud.lua` show the native clock ownership path. SurvivorUI retains the existing clock switch, mover, reset and guardian layout. Objective fields are omitted if absent or malformed. The new row uses separate values and never serves as a denominator for boss or Rift progress.
- **Warnings and ability tips.** Native `Spells.lua:124–139` distinguishes current `AZSSPELLTIP` from the offered `AZSCARDTIP` in `Cards.lua:1481–1491`. Session 033 contains ten distinct observed current text variants for Demonic Knowledge. The last native current tooltip matches the learned snapshot. No damage or cooldown formula was introduced. The warning hook preserves the native warning frame and game setting, and captures unknown text unchanged. [Official Addon API](https://azreborn.com/guides/addon-api)
- **Engineering principles.** `AGENTS.md` and `docs/CODE_REVIEW_GUIDELINES.md` now explicitly require native UI coexistence, existing component reuse and effort proportional to verified risk. This change leaves the runtime retirement gate, native jewelry attribution, History settlement and suppression of unsupported theoretical recommendations in their existing paths.
