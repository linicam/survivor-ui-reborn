## Presentation and data boundaries

The existing worn panel keeps its sizing, positioning, font and rarity-color settings. Each Reborn row displays the icon, item name and compact native effects. Both the worn panel and Run History use the same tooltip renderer for the full localized text, including conditional and special lines. Rows without reliable effect text show an unavailable state. Enhancement counts are omitted because this build has no verified count source. The original-client rank, name, slot and empty-slot options remain available on its inventory panel. Reborn's Options preview uses the same current source as the worn panel.

World entry, exit and a changed run ID invalidate the association with retained globals. A new zone snapshot establishes the context before accepting native equipment messages. Same-run replacement and explicit empties supersede prior results immediately. Native World equipment packets lack their own run ID, so an old packet arriving after a new valid zone packet is indistinguishable at the API boundary. Results depend on the native zone-first sync ordering. Final loot is held until the native end message. Entering an Endless continuation drops the preceding victory's reward observation from the live state. End messages without a matching live run can complete the existing summary fields, and absent equipment evidence remains unavailable. Existing history rows are retained in their original form.

## Evidence carried forward

The review uses observed records only. The test projection contains five sanitized native jewelry rows with neutral display names and no player, account or run identifiers from the capture.

- Of 84 retained card actions, 73 were picks. Spell offers carry structured before and after affix values. Ten observed picks associate with Demonic Knowledge, including initial acquisition. The observed damage bonus reaches +255% and extra targets reach +4. The final interval offer reports an uncapped candidate of 28% and the native interval-reduction cap is 20%. These values are upgrade modifiers.
- Jewelry offers observed include `new`, `grow`, `amulet` and `empower`, with native effect and detail fields available to a future progression store.
- A retained run observation has `target=1320`, `hunt="4,15"` and `fin=1200` independently. Future trackers should keep the objective clock and hunt counter distinct from the final boss timing.
